# 🎯 AIM//RUSH

A futuristic **aim training and reflex game** built using **HTML, CSS, and JavaScript**.

Test your reaction speed, hit as many targets as possible within 30 seconds, and try to beat your highest score.

## 🚀 Live Demo

https://hardahapulkit19-creator.github.io/aim-rush/

## 🎮 Features

* 🎯 Random target positioning
* ⏱️ 30-second gameplay session
* 🏆 Automatic high-score system
* 💾 High score saved using `localStorage`
* ⚡ Instant target movement after every hit
* ✨ Futuristic neon gaming interface
* 🎨 Glassmorphism-style UI
* 🖱️ Interactive crosshair gameplay
* 📊 Real-time score and timer
* 🔄 Play Again functionality
* 📱 Responsive design

## 🛠️ Technologies Used

* **HTML5** — Game structure
* **CSS3** — UI, animations and responsive design
* **JavaScript** — Game logic and interactions
* **LocalStorage** — High-score persistence

## 🕹️ How to Play

1. Open the game.
2. Click **START GAME**.
3. Hit the red target as quickly as possible.
4. Every successful hit increases your score.
5. The target moves to a random position after every hit.
6. You have **30 seconds** to score as many points as possible.
7. Try to beat your previous high score.

## 🎯 Objective

> **React fast. Aim accurately. Beat your high score.**

The game is designed to test your **reaction speed, accuracy, and hand-eye coordination**.
